# Security

Do not post credentials, account keys, or personal offer exports in public issues. For a suspected vulnerability, use GitHub's private vulnerability reporting option in the repository's Security tab.

Reports render captured text as text and protect CSV exports against spreadsheet formula execution. Background messages validate the extension sender and Amex origin. These protections are covered by tests.

Keep the extension updated and use the official repository/release files. The repository does not need your bank login to investigate a bug.
